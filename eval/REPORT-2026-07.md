## 평가가 잡아낸 결함 (측정 → 수정 → 재측정 루프)

같은 표본 이전 라운드는 발행 26건이었다. 라운드 사이에 평가가 직접 잡아낸 수정 6건:

1. K-Startup 마감 공고의 빈 셸 페이지 → ongoing↔deadline 형제 경로 폴백
2. 제출 URL 정규화가 상세 화면 파라미터(schM=view)를 제거하던 버그
3. 위험신호 스캔이 첨부 신청서 양식의 표준 문구(주민등록번호 동의란 등)에 오탐 → 랜딩 문서 한정
4. 추론 모델 토큰 절단: finish_reason=length 응답이 파서로 흘러 실패 → 버퍼 증량 재시도
5. Solar 장문 추출 타임아웃 180초 → 300초 (타임아웃 실패 19건 → 2건)
6. DOCX 첨부 미지원 → 파서 추가
