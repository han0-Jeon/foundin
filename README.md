# foundin

1인 창업자를 위한 정부지원사업 공고 관리 에이전트.

수백 건의 공고를 대신 읽고, 내 조건(지역·창업단계·업종·관심분야)에 실제로 신청 가능한 것만 골라
자격·지원금·마감일·필수서류·탈락 위험을 정리해 "오늘 확인해야 할 공고"와 다음 행동으로 알려준다.

> founding(창업)에서 g 하나를 뺀 이름이자, found in(찾아냈다)이기도 하다.

## 상태

Upstage Solar Agent Partner Program **Stage 1** 진행 중 (2026-07-17 ~ 2026-07-31).
설계 브레인스토밍 단계. 스택·아키텍처 미확정.

## Solar

| 항목 | 값 |
